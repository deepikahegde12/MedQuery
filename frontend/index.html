How it works

  1. Preprocess. The question is normalised, keywords are extracted, and its type is detected.
  2. Encode. A pretrained BERT model turns the question into an embedding for semantic search.
  3. Retrieve. An adapter queries the knowledge base and returns ranked passages with their sources.
  4. Extract. A BERT reading-comprehension model picks an answer span from those passages, with a confidence score.

BERT is used to understand questions and locate answers, not as a source of medical knowledge.
