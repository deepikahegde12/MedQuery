How MedQuery works

Four separate stages. If any stage cannot support an answer, MedQuery says so instead of guessing.

  1. 1

    Preprocess

    Unicode and whitespace normalisation, contraction expansion, keyword extraction, question-type detection and safety checks.

  2. 2

    Understand with BERT

    A pretrained BERT encoder tokenises the question into WordPieces and produces a contextual embedding for semantic search.

  3. 3

    Retrieve evidence

    A pluggable adapter queries the connected medical knowledge base and returns ranked passages with source references.

  4. 4

    Extract the answer

    A BERT reading-comprehension model selects an answer span from the evidence, with a confidence score.

About this project

MedQuery: An Intelligent Medical Question Answering System Using BERT and Knowledge Retrieval is a college mini-project. BERT is used to represent the meaning of questions and to locate answer spans in retrieved text. BERT is not a source of medical knowledge; every answer must come from the connected knowledge base.
